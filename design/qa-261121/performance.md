# 読み込みと重さ

## 読み込み

初回キャッシュなしの Chromium をローカル HTTP サーバーに接続し、タイトルから探索開始までを測定した。応答数は43、応答の Content-Length の合計は修正前 24,508,613 bytes、修正後 24,514,113 bytes。タイトル表示はそれぞれ 165ms、151ms。探索開始までの値にはテストの固定２秒待ちを含むため、通信時間の比較には使えない。ローカル環境での単回値であり、iPhone や携帯回線での待ち時間ではない。[修正前データ](before-load.json)／[修正後データ](after-load.json)

素材全体は125ファイル・127,252,620 bytes。うち立ち絵74ファイル・73,504,115 bytes、背景16,144,441 bytes、フォント17,238,203 bytes。画像・素材は軽量化していない。読み込み中の表示とフォント応答遅延時の８秒フォールバックを追加した。

## 長時間の相当試験

Chromium の仮想時計を30分進め、10分ごとに20回ずつ一覧の操作を行って GC 後の JavaScript ヒープなどを記録。修正前は開始時 1,271,352 bytes、10分 1,384,044、20分 1,398,596、30分 1,396,684。イベントリスナーは84→110→110→110。修正後のヒープは 1,741,940→1,851,176→1,867,716→1,875,316 bytes、リスナーは97→123→141→123。[修正前](before-lifetime.json)／[修正後](after-lifetime.json)

これは仮想時間の再現であり、実際に30分間遊んだ実機試験ではない。JavaScript ヒープには画像・Canvas・GPU などのネイティブメモリは含まれない。時間帯の光は Worker で計算し、その間も描画フレームが進むことを Chromium・WebKit で検証した。
