1. **コマンド**：マウス移動やフォーカスで一覧を開いていた → 拡大表示のみ。クリック・タップ・Enter・スペースで開く（`hover` / `click`）。選択中のコマンドは拡大を維持。
2. **聞く**：空の紙片 → 一覧を閉じ「ここには誰もいない。」。
3. **探す**：空の紙片 → 一覧を閉じ「まだ探す相手がいない。」。
4. **見せる**：空の紙片 → 一覧を閉じ「見せられるアイテムをまだ持っていない。」。相手不在の文は維持。
5. **追加項目のレ点**：机や掲示板を選ぶと追加項目にも付いていた → 場所・対象・項目名ごとに記録（`checks`）。
6. **続きのある項目**：調査済みなら常にレ点 → 今選ばれるイベントの配列番号を項目ごとに記録し、未読の続きでは外す。「聞く」も同じ形式。旧 `true` は読込時に選ばれるイベントを既読へ移行。旧設定に音の項目がなければON。
7. **長い一覧**：340pxで切れてスクロール → スクロールを廃止し人物より前へ。8項目を1920×1080・1280×720・390×844で画面内に表示（`eight`）。
8. **一覧の文字**：26px、最大152px → 22pxを基準に余白・字間を詰め、幅を広げた。長い名前は折り返す。
9. **PHS着信**：一覧見出しに重なった → 札の位置を移動（`mail`）。
10. **本文書体**：太い明朝 → Noto Serif CJK JP Lightを公式Noto CJKから取得し、既存書体とゲームの文字集合でサブセット化。OFLは既存 `assets/fonts/OFL-NotoCJK.txt`。原本：[notofonts/noto-cjk](https://github.com/notofonts/noto-cjk/blob/main/Serif/OTF/Japanese/NotoSerifCJKjp-Light.otf)。本文のみ300（`font`）。3サイズでシナリオの台詞180件の改ページ・欠けを検査。
