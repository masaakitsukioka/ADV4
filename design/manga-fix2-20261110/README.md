# 原稿用紙UI FIX2：作者デモに合わせた動き

2026-11-10 / v0.16.0 / 作業前コミット：0d30898

## 実装

- 白い紙2枚は探索・会話・推理で常設した。会話の開始・終了で変えるのは人物名・本文・送りの三角・選択肢だけ。最後の台詞を送ると文字が即座に消え、紙と立ち絵は残る。
- 探索と会話の切り替えで立ち絵をスライドさせない。話していない人の表情は直前のまま保ち、会話終了でも戻さない。通常へのリセットは場所移動と新規開始時に行う。メールへの会話反応も同じ舞台・紙・立ち絵の位置を使用する。
- 文字送りは「ふつう」60ms/文字、他は138ms・26ms・一瞬0msへ比率を保って調整した。18文字の確認台詞の全文表示まで約1.05秒。口パクは文字送り中だけ、瞬き・時間帯の光・上の欄・付せんは既存の仕組みを維持する。送りの三角は点滅する。
- 一覧は青い見出しから始め、紙片を上から80msずつずらして、短いフェードと下からの移動で表示する。選択中はtopic-circle.pngの横長の丸を紙片幅に合わせる。
- 一覧を同じ項目で作り直さず、会話後も選択位置と表示済みの紙片を保つ。項目が増えた場合も直前の選択を引き継ぎ、会話から戻る時の表示アニメーションは再実行しない。マウスで開いた一覧は紙片に乗るまで丸を出さず、キーボードで開いた時は先頭を選ぶ。
- その場の人に最後まで話を聞いた時のレ点を追加し、セーブに含めた。旧セーブに記録がない場合は空の履歴として読む。調べた場所のレ点は既存の記録を引き続き使用する。
- 会話開始時にフォーカスを会話の紙へ移す。コマンドのボタンにフォーカスを残した場合もEnter/Spaceで文字送りと次の台詞へ進める。会話選択肢と推理の回答ボタンのキー決定、IME・長押しの扱いは保つ。
- 小さい横画面とタブレット縦は、常設した紙や人物がコマンドを隠さない固定位置に調整した。探索と会話で位置を切り替えない。スマホ縦は従来どおり話者1人の表示を維持する。

コマンドの中身は変更していない。「聞く」はその場の人、「会話」は既存のランダム会話を1つ始める。scenario.js / scenario.jsonの内容、assets以下の素材画像に差分はない。ゲーム素材の生成・描き直し・加工は行っていない。出力画像は検証用の画面写真と動画の切り出しだけ。

## デモとの残りの違い

- 作者デモは御茶ノ水・朝、試作は既存の美術準備室・放課後。場所名、背景、台詞、場面に応じた表情と会話の長さは既存シナリオに従うため一致しない。動きを合わせるための新しい台詞や人物は追加していない。
- デモの「聞く」はサイジの話題一覧だが、作者決定に従い試作は「その場の人」のまま。現在の試作データにはその場の人物が設定されていないので「ここには誰もいない。」となる。聞き終えた人物のレ点・保存・旧セーブ互換は、ファイルを変えない実行時のテスト用人物でも検証した。
- 試作にはスケッチブック入手とPHS着信がある。これらは既存の内容として録画にも残している。比較用の最後の写真は一時的な着信通知が消えるまで待って撮影した。
- 小画面は操作性を優先した固定配置、動きを減らす設定では一覧の段階アニメーションと三角の点滅を停止する。1920×1080の通常表示の動きがデモとの比較対象。
