## 見本との差と理由

- 見本の部品画像 `A_*.png` はゲームでは使わず、実際のコマ、立ち絵、会話の紙、コマンドを動かす。そのため実際の会話文字や立ち絵の瞬きなど、固定画像の見本とは一部異なる。
- ４択の紙片は、現在の立ち絵と会話の紙にかからない安全領域へ配置した。問五は既存の「どの語も各空欄に選べる・入れ替えられる」操作を維持するため、見本の各空欄４語表示ではなく、従来の全語を並べる。縦画面では４列にして操作を維持する。
- 縮小画面では文字とボタンの最小サイズを確保しているため、見本より間隔や文字の大きさが異なる。
- 赤い丸は実際に選択中の紙片の画面上の範囲に合わせ、解いた問のレ点とともに白黒の外に描く。正解時の赤い印も外側に置く。画面の揺れは原稿側に適用し、赤入れとフラッシュは位置合わせを保つため独立した層に固定する。

## 白黒と問題文

原稿の各DOMを `#monoLayer` にまとめ、`grayscale(1) contrast(1.18) brightness(1.03)` を適用。赤入れ、フラッシュ、推理開始、正解の表示は兄弟の `#redLayer` に置く。層ごとの個別フィルターによる重さ対策は行っていない。推理中は場所ごとのトーン背景をコマに重ね、時間帯の光のキャンバスは表示しない。トーン画像がない場合は通常背景を原稿全体のフィルターで白黒表示する。

問題文はデータを変えず、先頭から最大12文字を１枚とし、その範囲の後半に「は・を・の・、」があれば最後の該当文字の直後で区切る。候補がなければ12文字で区切り、残りを同様に処理する。
