# 足音・アイテム入手の効果音（2026-11-18）

ゲーム内の音は `index.html` の `SE_SPEC` と `renderSE` でWeb Audio APIを使って合成する。音声ファイルはゲームから読み込まない。呼び出し窓口は `playSE('steps')` / `playSE('item')` にまとめているため、後から音声ファイル方式へ変更できる。文字音と同じAudioContextを使い、最初のポインター操作またはキー操作で再生可能にする。

## 音の値

- 足音：４歩、間隔0.15秒。各歩0.055秒。ホワイトノイズを中心周波数1400 / 1550 / 1380 / 1500Hz、Q=0.8の帯域フィルターへ通し、音量0.032 / 0.029 / 0.031 / 0.021で減衰。正弦波125 / 135 / 124 / 130Hzから75Hzへ下げる低音を、音量0.017 / 0.016 / 0.017 / 0.011で重ねる。最後の歩を弱くしている。
- 入手音：三角波784 → 1046.5 → 1318.5Hz。音間0.13秒、各音0.22秒、音量0.028から減衰。全体約0.48秒。

## 発音する時

- 移動先が現在地と異なり、`Events.enter` が成功した時に足音１回。同じ場所、ニューゲームの初期位置、セーブ読込では鳴らない。現行試作で場所が変わるルートはプレイヤーの移動と初期化・読込で、イベントによる別の場所決定は確認されなかった。
- イベントで新たに持ち物へ追加されたアイテムがあり、そのイベントの該当する最後のアイテム画像が表示される行で入手音１回。複数入手でも１回。すでに持っているアイテム、調査・「見せる」、セーブ読込では鳴らない。文字列では判定しない。
- 手帳「設定・操作方法」の「効果音：ON／OFF」は文字音とは独立。初期ON、セーブ対象。古いセーブに設定がなければONで読み込む。
