# 口差し替え画像の組み込み

立ち絵と同じ1040×1440の透明PNGに、口とその周囲の差し替え部分を描きます。立ち絵と位置を一致させ、余白を切り詰めないでください。閉じ口は立ち絵本体を使います。

新しい画像ができたら、`index.html` の `ASSETS.mouthFrames` と `assets.json` の `mouthFrames` に同じ設定を追加します。例：

```json
{"haruki":{"normal":[null,"assets/characters/talk/haruki-normal-mouth-1.png","assets/characters/talk/haruki-normal-mouth-2.png"]}}
```

登録後は同名画像の置き換えだけで更新できます。キャラクターと表情の既存IDは変更しません。サイジの既存 `saiji-<表情>-mouths.png` は、閉じ口・開き口1・開き口2を横に並べた3120×1440の画像にも対応します。

新しい口画像はまだありません。104×144の既存立ち絵では旧口パクを継続し、1040×1440の新しい立ち絵だけを入れた場合は口画像が揃うまで静止表示します。旧口の座標を新しい絵へ流用しません。今回画像の生成・変更は行っていません。
