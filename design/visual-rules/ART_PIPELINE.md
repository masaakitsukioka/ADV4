# 画像の作業分担と流れ（ラフ → 本番）

決定：2026-10-22（作者・Claude）／2026-10-26 改定：**ドット絵はやめた**（寸法は README 1章）
原則：**画像の「見た目を決める作業」はClaude、「ゲームに組み込む作業」はCodex。**
- **人物（立ち絵）**：ラフから作者が描き起こして仕上げる（最終の絵は人が描く）。
- **背景**：場面の資料（写真など）を集め、AIで生成する。生成の時にAIらしさ・不自然さが出ないようにする（スキル `saikachi-background`）。ドット絵には直さない。仕上げ方（作者の手直しの範囲・塗りの見た目）は検討し直し中

## 役割
| 作業 | 担当 | 理由 |
|---|---|---|
| ラフの生成（立ち絵・小物） | **Claude**（立ち絵はスキル `saikachi-character-rough`、背景・小物は `saikachi-rough-sketch`） | AIのくせを避ける指定・点検の手順をClaude側のスキルに一本化している。生成ツールを1つにすると画風と消費が管理しやすい |
| ラフの点検（構図・隠れる範囲・向き・時代考証） | **Claude** | 画像を見て判断する作業 |
| 画面の仕様（調べる場所・仮座標・ファイル名） | **Claude** → Codex作業指示書に記載 | ラフと同時に決める |
| ラフをゲームに仮表示する実装 | **Codex** | プログラム作業 |
| 背景の資料集め（写真・場面資料シート） | **作者**（撮影）＋**Claude**（資料の整理・時代考証） | 生成の指定は資料から書く |
| 背景の生成・点検 | **Claude**（スキル `saikachi-background`） | AIらしさを避ける指定と点検を一本化 |
| 立ち絵の清書（イラスト） | **作者** | 人物の最終の絵は人が描く |
| 背景の仕上げ | **作者**（＋Claude） | 方法は検討し直し中。ドット化はしない（2026-10-26） |
| 本番画像の点検（寸法・見た目） | **Claude** | 寸法（立ち絵1040×1440・背景1920×1080）と目視 |
| 本番への差し替え・調べる場所の座標確定 | **Codex** | プログラム作業 |

**Codexは画像を生成しない。** ラフが無くて作業が止まる時は、生成せずに灰色の箱と名前（例「作品棚」）の仮置きにし、Claudeにラフを依頼する。

## いつ作るか（段階）
1. **シナリオ・場面が決まった時（実装の前）**：Claudeがその場面のラフ一式と画面仕様を作り、Codex作業指示書に付ける。
   - 1つの指示書で使う画像は、その指示書を出す前にそろえる（実装中に後から足さない）。
2. **実装中（Codex）**：ラフを仮表示で組み込む。調べる場所の座標はラフ基準の仮の値。
3. **全プログラム完了後**：作者が清書（立ち絵）・背景の仕上げ → Claudeが点検。
4. **差し替え（Codex）**：同じファイル名のまま本番に入れ替え、座標を本番の絵で確定させ、テストを通す。

## ファイルの置き方（差し替えを「置き換えるだけ」にする）
- ラフ：`art_sources/rough/<種類>/<id>.png`（例 `art_sources/rough/backgrounds/classroom.png`）
  - 薄い灰色・「ROUGH」の透かし入り。生成に使ったプロンプトを同名の `.json` で残す。
- 本番：`assets/<種類>/<id>.png`（例 `assets/backgrounds/classroom.png`）
- **ラフと本番は同じ `<id>` を使う。** 読み込みは「本番があれば本番、無ければラフ」とする（`assets.json` に `stage: "rough" | "final"` を記録）。
- 本番の点検テストで、**公開用のビルドに `art_sources/rough/` の画像が1枚も使われていないこと** を確認する。

## Codex作業指示書に必ず書くこと
- 使う画像の一覧（`<id>`・種類・ラフのパス・本番が未着手であること）
- 調べる場所の名前と仮座標（1920×1080の座標系）
- 「画像は生成しない。足りない画像は灰色の仮置き＋Claudeに依頼」の一文

## 背景の流れ（2026-10-22 改定）
1. **資料集め**：作者が場所を撮影（または資料写真を集める）。Claudeが「場面資料シート」（場所・視点・主な物・雰囲気の小物・素材・1996年の時代考証・調べる場所）にまとめる。他人の写真は「何がどう置かれているか」を読む資料にだけ使い、そのまま生成に入れない。
2. **生成（Claude）**：資料シートから、写真調で生成する。AIらしさを避ける指定と点検はスキル `saikachi-background` に従う。1枚につき作り直しは最大2回まで。
3. **仕上げ**：ドット化はしない（2026-10-26）。仕上げ方は検討し直し中。寸法は1920×1080（元データ2560×1440以上。README 1章）。
4. **開発中の仮表示**：生成した画像（仕上げ前）を `art_sources/rough/backgrounds/<id>.png` に置き、Codexが組み込む。生成元の画像とプロンプトは `art_sources/generated/backgrounds/<id>.png`／`.json` に残す。
5. **全プログラム完了後**：作者が仕上げ、`assets/backgrounds/<id>.png` に置く → Claudeが点検 → Codexが差し替え。
- 生成元の画像のままでは製品に入れない（作者が仕上げた絵だけを使う）。
