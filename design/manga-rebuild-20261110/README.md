# 試作「消えたスケッチ」原稿用紙UI 再構築報告

2026-11-10 / 表示バージョン v0.16.0

## 実装

- 先行の未コミット作業を確認し、単体テストと9サイズの配置テストを通してから、`ec8f51e`「ドット絵をやめた表示への切り替え」として先にコミットした。並行して実施した先行版の315状態の画面監査も合格した。
- 作者の `manga-ui_261110b.html` を基準に、原稿用紙、上欄のハンコと時間の丸、傾いた墨枠、白紙2枚、新聞切り抜きコマンド、赤鉛筆の選択・調査済み印を実装した。会話は明朝、送りは本文末尾に表示する。
- 通常画面は1920×1080の舞台を縦横比を保って拡大縮小。小さい画面では文字と操作領域の下限を確保する。手帳は従来の配置を維持し、メールへの会話反応と推理は従来の画面レイヤーへ戻して表示する。
- ハルキ・サイジの口・目の差分は全身1枚を丸ごと切り替える。口は文字送り中のみ、瞬きは非発話時のみ2〜6秒間隔・70msで実行。旧口帯の登録と旧口座標による描画を外した。左右反転はしない。
- 調査済みの場所を保存対象 `progress.examined` に追加。旧セーブでは空の記録として読み込める。不正な場所・調査先・型を拒否し、新規開始時にリセットする。
- 背景座標を新しい絵の値に更新。調査点はコマ内のcover座標から配置し、コマと一緒に回転・拡大縮小する。
- 窓の光は `data/timeofday-params.json` と窓マスクからWorker＋OffscreenCanvasで計算し、場所・時間ごとにキャッシュする。昼は元画像のまま、計算中・失敗時も元画像を保持する。新しい場所は同形式の設定とマスクで追加できる。
- 調査先が多い場合は右端の紙片一覧をスクロール可能にし、上下キーとフォーカスでも続きへ移動できる。

## 変更していない内容

`data/scenario.js` と `data/scenario.json` は作業開始時のファイルとSHA-256が一致する。台詞・条件・手がかり・推理・シナリオmetaは変更していない。画像の生成・描き直し・加工・軽量化も行っていない。配置済みの画像をそのまま使用する。推理の新デザインは制作していない。

## テスト結果

合格：conditions / story / menu-phs / presentation-resolution / assets / ui-layout / ui-audit / logic / saves / stability / scene-transfers / portrait-animation / menu-phs-browser / manga-rebuild。

- ui-layout：1920×1080・1280×720・1024×768を含む9サイズ。会話、推理第5問、手帳、相関図、ロード画面の確認に合格。
- ui-audit：9サイズ×35状態＝315状態。画面外・文字切れ・36px未満の操作ボタン・隠れた操作・コントラスト不足・同梱外書体・JS/HTTPエラーは0件。PHS本体上の非操作用ミニ表示の小文字15種類だけは従来どおり除外。
- 追加確認：口パク全コマ・全文表示での閉口・瞬き・発話中の瞬き停止、調査済み印と旧セーブ互換、不正セーブと保存領域エラー、キー選択・文字速度・自動送り、場所名と背景、回転後の調査点、一覧のスクロールに合格。
- 光：2場所×朝・昼・放課後・夜を出力し、見本と左右に並べて目視確認。比較の数値も保存した。見本JPEGと無加工の昼PNGにも差があるため、完全な画素一致ではなく、その昼の基準差に対する追加誤差を検査している。

**既存の失敗を残したテスト：`tests/transfers.cjs`。** 旧VMが現在の外部表示スクリプトを読み込まず `showWindow` 未定義で停止する。また、その先の対象である `exportProgress` / `readSaveFile` などのセーブファイル持ち運びAPIは現行コードに存在しない。今回はこの別機能の復活を行わず、元のテストを変更せず残した。現在の場所・画面遷移は新設の `scene-transfers.cjs` で検証した。

## 仮置き・留意点

- 必要素材は揃っており、今回灰色の仮置きにした画像はない。
- PHS着信の表示は仮デザイン。メニュー付せんの近くに赤い「PHS 着信」の札を出す。未読がある間表示し、従来の着信通知も残す。
- スマホ縦は最低限の専用配置（900×1950の論理配置）で、話している1人だけを中央へ出す。原稿用紙と文字・ボタンを縦に組み直す。横画面を優先する方針は維持する。
- 腕を作者が修正予定の4差分は、指定どおり同じファイル名・位置合わせで後から上書きできる。
