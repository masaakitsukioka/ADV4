# 呼吸と推理画面の調整

2026-11-20の追加依頼に対応。基準はdd34fd8。画像を生成・変更せず、既存素材とHTML/CSSだけで調整した。問題文・選択肢・正解・台詞・セーブ形式は変更していない。pushは行わない。

## 変更内容

- 呼吸：周期3.6秒 / 4.3秒と振幅は維持し、開始位相をハルキ-0.35秒、サイジ-2.1秒に変更。2人の山谷が重なりにくいずれにした。瞬き・口パクは維持し、reduced-motionでは呼吸と弾みを止める。
- 質問と選択肢：固定240pxの質問欄を廃止して自然な高さへ変更。長い紙片は途中で折り返さず、元データの文字を欠かさず2枚に分ける。質問と選択肢の間を28px空け、背景コマを基準にグループ全体を中央配置。通常画面は質問56px・選択肢38px、小画面は従来の最小文字・操作サイズを保つ。スマホの長い選択肢は列の中で折り返す。
- 中央配置は、立ち絵の顔やスマホ上部の進行欄と重なる場合だけ上下に補正する。問五も内容の高さで配置し、スマホの単語一覧は6列にして背景内へ収める。正誤判定・文章の組み立て操作はそのまま。
- 正解！：赤い二重枠、少し斜めの押印、インクのかすれをCSSで表現。正・解の字幅は1em、細い!は0.45em、字間はどちらも0.12em。感嘆符だけ余白が膨らむのを防ぎ、枠内の文字組みを中央へ揃えた。読み上げ名は「正解！」。
- 右側の問一〜問五：書体・サイズ・傾き・上下ずれ・白黒の紙を混ぜた切り抜き文字に変更。再描画ごとに位置が跳ばないよう、疑似乱数で決めた装飾を固定している。今の問はボタンと同様に拡大し、解いた問の赤いレ点を維持。スマホは既存の横並びを継続する。
- 左上の「問一／五」：DOMも不要なCSSも削除し、右側の表示に一本化。
- 解明！：文字を150→210px（スマホ130→182px）とし140%に。1.8秒かけてゆっくり現れ、完全表示後1秒静止、0.5秒で消える。計3.3秒。reduced-motionは動かさず1秒静止してから進む。
- 解明後：現場背景をカラーへ戻し、立ち絵・上の欄・会話の紙を残す。右側は「解明済み」と五つのレ点を表示。最後は背景中央の読了カードと「タイトルへ」。捜査コマンドを再開させず、解明済みの一覧で空白を埋める。スマホの締めの台詞中は、操作できない付せんを隠して解決一覧との重なりを防ぐ。
