## 指定値との差・残る違い

- 小画面で従来の読みやすさ・タップ領域を保つため、文字の実表示12.5px以上、操作領域37px以上の既存方針を継続した。このため小画面では62pxの行や28px/22pxの文字などが必要に応じて大きくなる。通常画面の指定値には影響しない（戻るの最小高さも通常37pxで、指定の36px以上を満たす）。
- 高さ460px以下の横画面と701〜900px幅の縦タブレットでは、8項目＋戻るを画面内に収めるため、一覧topを136ではなく55、項目間隔を10ではなく0とした。その際、付せんが見出しを隠さないよう、この2種類のコンパクト画面だけメニューボタンもleft1100/top120へ移して背景コマの右上に置いた。通常画面の付せんと上の欄は変更しない。これ以外の画面はtop136・間隔10。スマホ縦は既存900×1950ステージの配置（一覧left530/top175/幅310、文字34px以上、戻る30px以上、行高90px以上、根コマンドtop10〜510を100pxおき）を維持している。
- 旧manga-fix1テストの「紙片同士に常に6pxの空白」は、新しい固定74px間隔・拡大1.28の指定と両立しない。指定値を優先したため、例えば1280幅で探すを拡大すると、回転した紙片の外接矩形は見せると約0.7px重なる。文字の中心は隠れず操作できる。旧テストは140msの拡大完了後の文字中心の操作性へ更新し、固定行位置と周辺5コマンド不動の検証は新テストへ追加した。余白を広げて指定値を変えることはしていない。
